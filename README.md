Ce dépôt contient le code source du site web du projet **Proxima's Quest**, développé par la **GodMEL Corporation**.

Le site présente le projet, son univers, l’équipe, ainsi que divers médias et documents associés.

---

## 🚀 Technologies utilisées

- HTML / CSS / JavaScript

---


## 📁 Structure du projet

- `index.html` : Page d’accueil  
- `download.html` : Téléchargement des différentes versions du jeu, avec images  
- `story.html` : Présentation de l’histoire et de l’équipe  
- `ressources.html` : Outils utilisés et documents du projet  

### Répertoires

- `assets/img/` : Images  
- `assets/fonts/` : Polices utilisées  
- `assets/exe/` : Exécutables du projet  
- `assets/css/` : Feuilles de style CSS  
- `assets/js/` : Scripts JavaScript  
- `assets/dos/` : Documents du projet (Rapports, plans, etc.)
